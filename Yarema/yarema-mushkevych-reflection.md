# Yarema Mushkevych's Project Reflection

This is my reflection for the widget sorter project

## What Challenges Did I Overcome?

During this project, I helped with the wiring and Arduino code. In the wiring department, I mainly had to overcome issues with a lack of space on the breadboard and figuring out how to wire everything up. In the coding department, I learned how to program servos and how to better structure my code by using functions instead of one giant main line. 

## What Would I Do Differently?

If I were to do this project again, I'd definitely solder the LEDs so that I could free up space on the breadboard. I'd see if I could make the wiring more compact and not as prone to breaking as it is right now. Perhaps I'd switch from LEDs to an LCD display so that I could display more than just a binary count.

## What Did I Learn In Project 1 That I Applied To Project 2?

In 'Project 1,' I learned how to write code for a Hobby Gearmotor, which helped me then write the code for the linear actuator, which is effectively the same thing. My previous experience with Arduino projects in general allowed me to understand how wiring and code would work, which helped speed up the construction process.
